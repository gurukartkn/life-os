# Life OS — Wireframes (Phase 5)

Source (visual canvas — view for pixel-level structure): https://claude.ai/artifact/6NXfKtUZcqrMG2HQWRn1R2

> These wireframes are a visual canvas artifact (low-fidelity structural layouts), not a text document — open the link above to see them directly. This file captures the approved scope and screen list as a text reference for implementation.

**Scope:** all MVP domains in one pass — app shell + Today/Todo, Fitness, and Routines.
**Fidelity:** a single structure per screen, not multiple layout options per screen.

## Approved screens

1. **Shell + Today**
   - Sidebar nav (Today, Todo, Fitness, Routines)
   - Stat row (summary numbers across domains)
   - Add-todo inline form
   - Todo list

2. **Fitness Overview**
   - Workouts / Exercises tabs
   - Workout cards (named templates)
   - Recent logs section

3. **Fitness Log Workout**
   - Active logging session
   - Per-set inputs (weight/reps or duration)

4. **Routines**
   - Routine list
   - Selected routine's daily checklist

These four screens map directly onto the PRD's Section 5 screen inventory (Today dashboard, Domain List View pattern, Entity Detail/Editor, and the Fitness-specific logging flow) and carry forward unchanged into the Phase 6 high-fidelity mockups — see `07-mockups.md`.
